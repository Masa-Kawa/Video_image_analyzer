# チュートリアル: アノテーション編集Webアプリを使う

自動生成したフェーズSRTを、**ブラウザ上で動画を見ながら手で直す**ための実践ガイドです。
インストールから、実際の修正操作、保存済みファイルの再編集、修正履歴の確認までを順に説明します。

> このアプリは**手元のPC内だけ**で動きます（既定で `127.0.0.1` のみ待受）。GitHub等には何も送信されません。
> 仕様の詳細は [annotation_editor.md](annotation_editor.md)、解析全体の流れは [../TUTORIAL.md](../TUTORIAL.md) を参照。

---

## 0. 準備（初回のみ）

```bash
cd video_data_analyser
uv sync          # 依存をインストール（fastapi / uvicorn / av など）
```

必要なもの:

- **動画ファイル**（例: `case001.mp4`）
- （任意）**編集したいSRT**（例: フェーズ認識の出力 `case001_phase.srt`）。無くてもゼロから手付けできます。

---

## 1. 起動する

### 既存のSRTを修正する場合

```bash
python -m src.annotate.server \
    --video case001.mp4 \
    --srt out/case001_phase.srt \
    --procedure cholecystectomy \
    --port 8000
```

### ゼロから作る場合（ゴールドラベル付け）

`--srt` を省略すると、空の状態から区間を手で作っていくモードになります。

```bash
python -m src.annotate.server --video case001.mp4 --procedure cholecystectomy
```

起動すると、

1. ブラウザ再生用の軽量プロキシ（480p）が自動生成され（初回は数十秒かかることがあります）、
2. 既定でブラウザが自動で開きます（開かない場合は **http://127.0.0.1:8000/** を手動で開く）。

> `uv run` がキャッシュ権限エラーになる環境では、`uv` を付けず `python -m src.annotate.server ...` で起動してください。

ターミナルには保存先が表示されます:

```
[server] http://127.0.0.1:8000/
[server] 保存先: out/case001_gold.srt
[server] ペア : out/case001_gold_dpo_pairs.jsonl
[server] 履歴 : out/case001_gold_history.jsonl
```

## 2. 画面の見かた

```
┌───────────────────────────────────────────────────────────┐
│ case001.mp4   [修正]            状態表示   📂開く 🕘履歴 保存(Ctrl+S) │  ← 上部バー
├──────────────────────────────┬────────────────────────────┤
│                              │ フェーズ（数字キーで付与）   │
│         動画プレイヤー         │ [1]Preparation [2]Calot... │  ← パレット
│                              ├────────────────────────────┤
│  00:02:15,600 / 00:48:00,000 │ 選択中セグメント            │
│ ┌──────────────────────────┐ │  ラベル: CalotTriangle...  │
│ │ ▓▓▓ ░░ ▓▓▓▓ ░ ▓▓ │ ← タイムライン │  開始 [00:03:48,228] I  │  ← 編集パネル
│ └──────────────────────────┘ │  終了 [00:05:37,337] O  │
│   （区間バーをクリックで選択）  │  ＋挿入(N)   🗑削除(Del)  │
│                              ├────────────────────────────┤
│                              │ 1. Preparation  00:00→03:47│  ← 区間リスト
│                              │ 2. Calot...     03:48→05:37│
└──────────────────────────────┴────────────────────────────┘
 Space:再生  ←/→:1秒  Shift+←/→:区間移動  I/O:端をスナップ  …    ← ヘルプ
```

- **タイムライン**の緑のバー1本が1区間（フェーズ）です。クリックすると選択され、その先頭に頭出しします。
- 右側の**区間リスト**からも同じ選択ができます。
- 選択中の区間は**編集パネル**でラベル・開始・終了を編集します。

---

## 3. キーボード操作 早見表

| キー | 動作 |
|------|------|
| `Space` | 再生 / 停止 |
| `←` / `→` | 1秒もどす / すすめる |
| **`Shift+←` / `Shift+→`** | **前 / 次の区間の先頭へジャンプ**（その区間を選択） |
| `I` | 選択区間の**開始**を、今の再生位置に合わせる |
| `O` | 選択区間の**終了**を、今の再生位置に合わせる |
| `1`〜`9` | 選択区間に**フェーズを付与**（パレットの並び順） |
| `N` | 今の再生位置に**新しい区間を挿入** |
| `Del` / `Backspace` | 選択区間を**削除** |
| `Ctrl+S` | **保存** |

> 時刻入力欄（`HH:MM:SS,mmm`）にカーソルがあるときは、ショートカットは無効になります（数値入力を優先）。

---

## 4. 実際に直してみる（基本の流れ）

例として「2番目の区間の開始が少し早すぎる＋ラベルが間違っている」のを直します。

1. **区間を選ぶ**: タイムラインの2本目のバー（または区間リストの2番）をクリック。動画がその先頭に飛びます。
2. **境界を確認する**: `Space` で再生し、`Shift+→` で次の区間へ飛びながら、どこが本当の境界かを目で確認します。
3. **開始位置を直す**: 正しい開始フレームで一時停止し、`I` を押す。→ 選択区間の**開始時刻が今の再生位置にスナップ**します。
   （終了側を直したいときは、正しい位置で `O`。）
   - 細かく数値で直したいときは、編集パネルの開始/終了欄に `00:03:48,228` のように直接入力してもOK。
4. **ラベルを直す**: パレットを見て正しいフェーズの番号を押す（例: `2`）。→ ラベルが置き換わります。
5. **要らない区間を消す / 足りない区間を足す**:
   - 誤検出の区間 → 選択して `Del`。
   - 抜けている区間 → 入れたい位置に頭出しして `N`（次の区間の手前まで自動で伸びます）。
6. **保存する**: `Ctrl+S`。上部バーに「保存完了: N セグメント / 今回の変更 M 件」と出ます。

> 未保存の変更がある状態でタブを閉じようとすると、確認ダイアログが出ます（直し忘れ防止）。

---

## 5. 保存すると出るファイル

保存（`Ctrl+S`）するたびに、同じ場所に3つ更新されます。**元のSRTはそのまま残ります。**

| ファイル | 中身 |
|----------|------|
| `case001_gold.srt` | 直したあとの確定SRT（安定ID付き）。これが成果物 |
| `case001_gold_dpo_pairs.jsonl` | 「自動生成（rejected）／人の修正（chosen）」の学習用ペア |
| `case001_gold_history.jsonl` | 保存ごとの**変更点の履歴**（次項） |

---

## 6. 保存済みを後からまた直す（再編集）

いったん保存したあと、別の日に続きを直したい場合:

1. 上部バーの **📂 開く** をクリック。
2. ダイアログで:
   - **動画パス**: `case001.mp4`（元の動画）
   - **編集するSRTパス**: 先ほどの **`out/case001_gold.srt`** を指定 ← ここがポイント
   - 術式を選ぶ
3. **開く** を押すと、保存済みの内容が**安定IDを保ったまま**読み込まれ、続きから修正できます。

> 別の動画に切り替えるときも同じ **📂 開く** を使います（パスを入れ替えるだけ）。
> 未保存の変更があるときは、破棄してよいか確認が入ります。

---

## 7. 修正履歴を見る

上部バーの **🕘 履歴** をクリックすると、**保存ごとの変更点**が新しい順に並びます。

```
case001_gold_history.jsonl（3 回保存）
─────────────────────────────────────────────
2026-06-11T08:34:53+00:00 ・ 変更1件（編集1/追加0/削除0）
   ±編集  CalotTriangleDissection [00:03:48→05:37] ⇒ GallbladderDissection [00:03:48→05:37]
2026-06-11T08:30:10+00:00 ・ 変更2件（編集1/追加1/削除0）
   ＋追加  Clipping [00:12:00→00:13:30]
   ±編集  Preparation [00:00:00→03:47] ⇒ Preparation [00:00:00→03:50]
```

- 各行が「いつ・何を・どう変えたか」です（編集＝前→後、追加、削除）。
- 変更が0件の保存（誤って `Ctrl+S` しただけ）は履歴に残りません。
- タイムスタンプは UTC（`+00:00`）で記録されます。

---

## 8. 困ったとき

| 症状 | 対処 |
|------|------|
| ブラウザが自動で開かない | **http://127.0.0.1:8000/** を手動で開く。`--no-browser` で自動起動を抑止も可 |
| `Address already in use`（ポート使用中） | 既に起動済み。別ポートにするなら `--port 8001` |
| `uv run` がキャッシュ権限エラー | `uv` を付けず `python -m src.annotate.server ...` で起動 |
| 起動時にプロキシ生成で待つ | 初回のみ。次回以降はキャッシュされて速い |
| 「許可ディレクトリ外のパスです」 | 📂開く で指定できるのは起動時の作業ディレクトリ配下のみ。外を開くなら `--base-dir` を広げて起動 |
| 動画は別の場所にある | 起動時 `--video` には任意のパスを指定可。UIの📂開くは `--base-dir` 配下に限定される点に注意 |

---

## 9. 終了する

ターミナルで `Ctrl+C` を押すとサーバが止まります。保存済みファイル（`*_gold.srt` など）はそのまま残ります。

---

## まとめ

```
起動（--video / --srt）
   → 区間を選ぶ（クリック / Shift+←→）
   → 境界を I / O でスナップ、ラベルを 1〜9 で付与、N 挿入 / Del 削除
   → Ctrl+S で保存（gold.srt + 学習ペア + 履歴）
   → 後日 📂開く で gold.srt を再編集、🕘履歴 で変更点を確認
```
